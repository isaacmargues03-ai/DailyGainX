# **App Name**: DailyGainX

## Core Features:

- Deposit Funds: Allow users to deposit USDT into their account with a minimum deposit of 20 USDT, or any other specified amount above that.
- Profile Display: Display the user's profile information, including profile picture (to be added later), name, and Gmail address.
- Investment Simulation (Rogério Machine): Simulate an investment machine labeled 'Rogério' where users can deposit 20 USDT. Display the percentage completion towards the withdrawable amount, which will be reached in 5 days.
- Balance Display: Display the user's balance in USDT.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) to provide a clean and trustworthy feel.
- Background color: Dark blue (#00008B), desaturated to 20%, for a professional and modern backdrop (#1A1A5A).
- Accent color: A slightly more saturated blue (#4682B4), which is about 30 degrees away from light blue, providing good contrast.
- Body and headline font: 'Inter', a sans-serif with a modern, neutral look suitable for both headlines and body text.
- Use clean and modern icons for navigation and key actions.
- Maintain a clean and intuitive layout with clear sections for deposit, profile, and investment details.
- Use subtle animations and transitions to enhance user experience and provide feedback on actions.
